# Kushagra Innovations — Portfolio

A responsive, dark, premium personal portfolio for GitHub Pages.

## Deploy to GitHub Pages

1. Create a GitHub repository, for example `kushagra-innovations`.
2. Upload `index.html`, `style.css` and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your site will be available at `https://YOUR-USERNAME.github.io/kushagra-innovations/`.

## Before publishing

Replace placeholder project links (`href="#"`) with your real demos/source-code URLs. Update social links if needed and add real project screenshots as the portfolio grows.

For a custom domain, add your domain in GitHub Pages settings and configure the DNS records at your domain provider.
